# Ultra Product

## Register

product

## Users

Developers working in project-scoped terminals with coding-agent CLIs. They use Ultra to keep agents, shells, files, context, and source control in one focused desktop workspace.

## Product Purpose

Ultra is a native-feeling terminal harness for running external coding agents. It should make long-running agent work visible and manageable without getting between the developer and the terminal.

## Brand Personality

Focused, capable, understated. Ultra should feel like a precise macOS tool: responsive, familiar, and quietly distinctive.

## Anti-references

Avoid decorative SaaS-dashboard styling, oversized controls, gratuitous cards, novelty interactions, and visual effects that compete with terminal work.

## Design Principles

- Keep the terminal and active task visually primary.
- Prefer familiar desktop affordances over invented controls.
- Show agent state clearly without demanding attention.
- Make persistent behavior explicit and easy to reverse.
- Preserve a compact, consistent vocabulary across panels and settings.

## Accessibility & Inclusion

Support light and dark appearances, keyboard and assistive-technology semantics, visible focus states, adequate contrast, and the operating system's reduced-motion preference.
